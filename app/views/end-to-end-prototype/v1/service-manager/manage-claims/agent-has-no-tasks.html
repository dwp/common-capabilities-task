Reviewing and returning tasks to the queue

  • Select ‘Active’ as the status.
  • Select 'Search'.
  • Review and return any tasks to the queue.
  • Repeat these steps selecting 'Allocated' as the status.
  • Repeat these steps selecting 'On hold' as the status.

Once you have done this, go back to the user profile and remove the user from the organisation.
